## Topology (final)

```
Claude Code ──MCP/HTTP──> Everywhere (.NET, :7878/mcp)
                                │
                                ├── local tools  (everywhere.*  +  clipboard_*, batch)
                                │
                                └─ WebSocket ──> OpenDia browser extension
                                                       │
                                                       └─> page (browser_*)
```

- **Everywhere** is the only MCP server Claude sees.
- **OpenDia** is a standalone WebSocket service. Anyone speaking the WS
  protocol drives it; Everywhere is one client.
- Universal capabilities ship **twice** (once on each substrate).
- Tool naming: `browser_*` (forwarded to extension via WS) and
  `everywhere.*` (local). Forwarding is automatic via
  `OpenDiaToolListBuilder.Prefix = "browser_"`.
