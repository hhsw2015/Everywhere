## Topology (final, after 4 corrections)

```
Claude Code ──MCP/HTTP──> Everywhere (.NET, :7878/mcp)
                                │
                                ├── local tools     (everywhere.*)
                                │
                                └─ WebSocket ──> OpenDia browser extension
                                                       │
                                                       └─> page
```

- **Everywhere** is the only MCP server Claude sees.
- **OpenDia** is a standalone WebSocket service (the browser extension is
  the WS server). Anyone speaking the WS protocol can drive it; Everywhere
  is one client.
- Universal capabilities ship **twice** — once in the extension, once on
  the Everywhere side — so neither component loses standalone usefulness
  when the other is uninstalled (SPEC §2.1 + §3.1).
- MCP tool naming: `browser_<name>` (forwarded to extension via WS) and
  `everywhere.<name>` (local). Matches the existing
  `OpenDiaToolListBuilder.Prefix = "browser_"` in
  `src/Everywhere.Mcp/OpenDia/`.
